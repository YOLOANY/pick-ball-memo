\# 拾球记 pick‑ball‑memo

> 🎓 大创竞赛项目｜高校运动资源共享微信小程序



\## 📖 项目简介

拾球记是面向高校在校学生的运动资源共享小程序。

解决校园运动场景痛点：约球找人难、运动场地信息不透明、闲置运动器材浪费。

实现\*\*约球组队、场地预约、器材共享租借、运动打卡动态广场\*\*四大核心功能。



技术方案采用微信小程序原生开发 + 微信云开发，无需自建服务器，降低部署与维护成本，适合校园竞赛演示。



\## ✨ 核心功能

1\. \*\*用户模块\*\*

微信一键授权登录；个人中心管理我的发布、约球、租借记录、运动打卡。



2\. \*\*约球组队（核心）\*\*

发布约球帖子，填写运动项目、时间、地点、招募人数；帖子列表浏览、申请入队、留言评论。



3\. \*\*校园场地预约\*\*

网球场、羽毛球场等校园场地展示；选择日期时段提交预约，查看个人预约记录。



4\. \*\*运动器材共享租借\*\*

学生发布闲置运动器材出借信息；浏览器材列表，发起租借申请。



5\. \*\*运动打卡动态广场\*\*

发布运动动态，支持上传图片与心得；广场浏览全校同学运动分享。



6\. \*\*简易管理能力\*\*

基于云数据库权限实现违规帖子删除，不搭建复杂后台管理系统。
